# Module 6: Wrap-Up and Next Steps

**Linux for Bioinformatics for Life Scientists · Bowen University · 16–18 November 2026**

## Overview

You have now run two complete analyses from raw reads to a result. This module pulls them together. It puts each workflow on a single page so you can see the shape of it, introduces the take-home capstone, and points you to where to learn more.

There is no new material here. If something still feels unclear, this is the place to go back over it.

## Learning objectives

By the end of this module you will be able to:

- Describe the short-read (Ebola) workflow from start to finish, and what each step checks
- Describe the long-read (cassava) workflow in the same way
- Compare the two workflows: what is the same, and what is different, and why
- Explain what the capstone asks you to do and how to submit it
- Choose next steps for continuing to learn bioinformatics
