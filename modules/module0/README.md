# Module 0: Getting Set Up

**Linux for Bioinformatics for Life Scientists · Bowen University · 16–18 November 2026**

## Overview

This module gets your own computer ready for the course. You install a Linux terminal, a software manager called Conda, and the bioinformatics tools and training data we use throughout. **Please complete it before the training begins.** It takes roughly 45 to 90 minutes, mostly waiting for downloads.

If your computer cannot run what is needed, or you get stuck, do not worry: a temporary online login with everything already installed is available. See Part 1 of the guide.

## Learning objectives

By the end of this module you will have:

- Checked whether WSL (Windows Subsystem for Linux) is installed on your Windows computer
- Installed Ubuntu and opened your first terminal
- Installed Miniforge, which provides Conda
- Created the `bioinfo` environment with the course tools
- Downloaded and unpacked the training data

## Before you begin

You need a laptop with at least 15 GB of free disk space and a reliable internet connection. Windows 10 (version 2004 or newer) and Windows 11 are supported. Mac users have their own section in the guide.

## Getting help

Email **bioinformaticsfridays@gmail.com** with a short description of the problem, the part of the guide you were on, and a screenshot of any error message.
