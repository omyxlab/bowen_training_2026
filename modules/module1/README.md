# Module 1: Welcome and Introduction to Bioinformatics

**Linux for Bioinformatics for Life Scientists · Bowen University · 16–18 November 2026**

## Overview

Before we open the terminal, this module gives you the background you need to make sense of everything that follows: what the course is about, what bioinformatics is, how DNA and RNA are sequenced, what the resulting files look like, and where biological data are stored.

These lessons go with the slide presentation. They are written so that you can follow the slides and then reread the details later. **You do not need a terminal for this module.**

## Learning objectives

By the end of this module you will be able to:

- Describe what the course covers and how it fits together
- Explain what bioinformatics is and why life scientists use the command line
- Compare the main sequencing technologies and say which suits which question
- Recognise FASTA, FASTQ, GFF3, SAM/BAM, VCF and BED files and read the main fields in each
- Explain what a Phred quality score means
- Name the major biological databases and read an accession number
